Hello, this is my VGP236, Programming for Game Engines midterm.

We were tasked with creating a maze game with three keys that when picked up would unlock the exit. When hitting the exit it would stop a timer. We were also tasked to add UI.

I believe I have it set up on GitHub where you need to put the Midterm folder into your Unity project Assets folder. From there, you can open the scene up and play the maze game in Unity.

The most challenging part of this assignment was actually constructing the maze itself. It was a bit awkward to position all walls within the camera, but it was great practice and I'm getting used to it.
